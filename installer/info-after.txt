ติดตั้ง DeFeedback เรียบร้อยแล้ว

โปรแกรมเดี่ยว (ไม่ต้องมีโปรแกรมทำเพลง)
  เปิดจาก Start Menu > DeFeedback
  ครั้งแรกให้ตั้งค่าอุปกรณ์ก่อน กดปุ่ม Settings ในโปรแกรม
    Audio device type - เลือก ASIO ถ้ามี ไม่มีให้ใช้ Windows Audio (Exclusive Mode)
    Input  - เลือกไมค์หรือการ์ดเสียงที่ต่อไมค์
    Output - เลือกลำโพงหรือการ์ดเสียงที่ออกลำโพง
    Sample rate 48000 และ Buffer size 256 เป็นจุดเริ่มที่ดี
  ถ้าเสียงหน่วง ให้ลด Buffer size ลง ถ้าเสียงสะดุดให้เพิ่มขึ้น

ปลั๊กอิน VST3
  CUBASE / NUENDO
    Studio > VST Plug-in Manager แล้วกด Update
    ถ้ายังไม่ขึ้น ปิด Cubase แล้วเปิดใหม่
    ปลั๊กอินอยู่ในหมวด EQ หรือพิมพ์ค้นหาคำว่า defe
  REAPER / STUDIO ONE / อื่น ๆ
    สั่ง rescan VST ในหน้า preferences ของโปรแกรมนั้น

  หมายเหตุ Waves MultiRack ใช้ไม่ได้ เพราะรับเฉพาะปลั๊กอินฟอร์แมต SoundGrid
  ถ้าใช้ Waves ต้องเป็น SuperRack Performer V14 ขึ้นไป


การตั้งค่าเริ่มต้นเหมาะกับไมค์ร้องในงานไลฟ์อยู่แล้ว

ถ้าอยากปรับ
  จับเสียงหอนช้า          ลด FB Peak Threshold
  ไปกินโน้ตที่ลากยาว      เพิ่ม FB Detect Time
  อยากจัดเสียงไมค์มากขึ้น  ลด Res Threshold เป็น 3
  เสียงบางไป              ลด Res Depth
  อยากล้างค่าที่จับไว้      กด Reset All

ตัวจัดการเรโซแนนซ์ต้องรอราว 3-4 วินาทีหลังมีเสียงถึงจะเริ่มทำงาน
